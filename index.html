🐸 工作台使用指南

这个工作台融合了两大经典方法论：

1. 吃掉那只青蛙（博恩·崔西）
每天先攻克最难、最重要、最有价值的任务。"青蛙" = 你最想拖延但完成后价值最大的事。

2. 成功人士每日计划
通过晨间仪式启动一天，时间块管理聚焦要务，晚间复盘持续精进。

📋 使用流程：

前一晚 / 晨起 → 填写三只青蛙（按难度排序，最丑的放第一）→ 用ABCDE法列出所有任务 → 规划时间块
晨间 → 完成晨间启动仪式 → 直接吃掉第一只青蛙（不要先看邮件/刷手机！）
白天 → 按时间块专注执行 → 单任务推进直到完成
晚间 → 复盘四问 → 记录感恩与手记

💡 ABCDE 优先级法：

A = 必须做，不做有严重后果（你的青蛙）
B = 应该做，但不做后果不严重
C = 做了大家都愉快，不做也无妨
D = 可以授权给他人
E = 完全可以删除

⚠️ A任务没完成前，绝不要先做B任务。所有数据自动保存在本地浏览器中。
